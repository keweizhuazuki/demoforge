# DemoForge

产品会变，演示也应该跟得上。

[English](README.md)

DemoForge 是本地运行的产品演示工作台：真实执行浏览器流程、保留截图证据，用可编辑的镜头、字幕和节奏导出 MP4 与离线交互教程。UI 改版后可以重跑相同流程，并排比较新旧版本，再决定是否批准替换。

## 完整闭环

- React 可视化创作界面：场景列表、预览、时间线、字幕、时长、镜头缩放
- Playwright 真实执行导航、点击、输入、等待和断言；失败保留已完成截图
- 已批准版本与候选版本分开，不会静默覆盖旧素材
- 真正导出 H.264 MP4 和包含截图、热点、键盘导航的单文件 HTML 教程
- 可选 AI 提出叙事顺序、镜头取舍、字幕、节奏和构图，必须由你审阅应用，不会自动执行浏览器代码

## 启动

需要 Node.js 24、FFmpeg（含 libx264）与 Chromium 依赖。Ubuntu 是 CI 运行目标，macOS/Windows 尚未验证。

```sh
npm ci
npx playwright install --with-deps chromium
npm run build
npm start
```

打开 http://127.0.0.1:4317。核心流程不需要 API key，不需要付费模型。

先录制经典版示例并批准，再选择刷新版重录；修改字幕、时长、缩放或导出镜头顺序后，预览实际导出视频。示例应用是明确标注的虚构产品。

## AI 与密钥

AI 默认关闭。可选 OpenAI / Anthropic 服务端适配器，模型由使用者配置。复制 `.env.example` 为本地 `.env` 后配置，使用 `node --env-file=.env server/index.mjs` 启动。密钥绝不能写进前端、GitHub、聊天、演示素材或日志。

点击建议后会发送创作简述和场景 ID/标题/字幕，不发送截图或浏览器动作。请先设置服务商消费上限。每次最多 1600 输出 token，45 秒超时；这不是美元级消费保证。当前未使用真实付费密钥验证模型输出质量。

## 当前边界

这是本地开发者预览版，默认录制内置 `/demo` 示例，也可在服务端通过 `DEMOFORGE_TARGET_ORIGIN` 显式配置一个自己的应用来源，并在界面确认权限后录制。仅允许同源 GET、全新未登录上下文，不支持 POST API、第三方资源、WebSocket、登录账号或多人服务。请只使用合成数据并检查截图中的敏感信息。MP4 是基于真实截图的动画镜头，不是连续屏幕录像。暂无音轨、协作审批、自动发布和语义差异检测。详情、测试与路线图见英文 README。
